Four Excel tasks to try in your own workbook

Keep an input editable, restrict typed quantities, classify a total and build a chart with two axes. Each free exercise includes fictional data and a worked answer you can compare with your result.

Before you start

You need an existing licensed installation of Excel for Microsoft 365 desktop on Windows. Use English function names, comma formula separators and a decimal point. Start each task on a fresh sheet in a disposable workbook, with calculation set to Automatic.

To copy a data box, focus it, select all with Ctrl+A and copy with Ctrl+C. Paste into the cell named above it. Tabs separate columns. If the data lands in one column, use Data > Text to Columns with Tab as the delimiter. Check that numbers are numeric and formulas calculate before continuing.

This page does not run Excel or grade your workbook; check your result manually.

Q01 / Worksheet controls

Leave an input cell editable

Allow changes to B2 while protecting the formula in C2 from edits. Use no password for this disposable exercise.

C2 should initially show 120. After protecting the sheet, change B2 to 9 and try to overwrite C2.

Reveal Q01 worked answer and checks
  1. Select B2. Open Format Cells > Protection and clear Locked. Leave C2 locked.
  2. Choose Review > Protect Sheet. Leave the password blank. Keep both Select locked cells and Select unlocked cells checked so you can select C2 for the attempted edit.
  3. Change B2 to 9. C2 should show 135. Attempting to overwrite C2 should be blocked.

Cell locking takes effect when the sheet is protected. The unlocked input can change while the formula continues to calculate. Worksheet protection controls editing; it does not keep confidential data secure.

To reset, choose Review > Unprotect Sheet and restore B2 to 8.

Q04 / Data entry

Restrict typed quantities

Configure empty B2:B6 to accept whole numbers from 1 through 12, inclusive. Use a Stop error alert. Blank cells may remain.

After setting the rule, type each fictional test value directly into B2: 1, 12, 0, then 2.5. Cancel invalid entries. Do not paste the test values: this task checks direct typing only.

Reveal Q04 worked answer and checks
  1. Select B2:B6 and choose Data > Data Validation.
  2. On Settings, set Allow to Whole number, Data to between, Minimum to 1 and Maximum to 12. Leave Ignore blank checked.
  3. On Error Alert, enable the error alert after invalid data is entered and choose the Stop style. Confirm the dialog.
  4. Type the test values into B2 one at a time. Both 1 and 12 should be accepted. Both 0 and 2.5 should trigger the Stop alert; choose Cancel for each rejected entry.

The whole-number rule rejects fractions, and the inclusive limits exclude zero. Data validation is not a security boundary. Pasting is outside this check.

To reset the exercise, use a fresh sheet with B2:B6 empty.

Documentation: Apply data validation to cells (Settings and Error Alert); More on data validation (limitations).

Q09 / Formulas

Classify a conditional total

In E2, use IF and SUMIFS to return Target met when the total for North rows with Paid status is at least 70. Otherwise return Below target. Work out the qualifying total too.

Reveal Q09 worked answer and checks

Enter this formula in E2:

=IF(SUMIFS(C2:C5,A2:A5,"North",B2:B5,"Paid")>=70,"Target met","Below target")

The qualifying rows contain 40 and 35. Their total is 75, so E2 should show Target met. SUMIFS requires both conditions to match; it excludes North/Open and South/Paid.

For another check, change C5 from 35 to 25. The total becomes 65 and E2 should show Below target. Set C5 to 30 to check the boundary: 70 should show Target met. Restore C5 to 35 afterward.

Documentation: SUMIFS syntax and criteria; Excel functions by category (Logical functions: IF).

Q15 / Charts

Put a percentage on a secondary axis

Create a combo chart with Revenue as clustered columns on the primary axis and Margin as a line on the secondary axis. Format the secondary vertical axis as percentages. Title the primary vertical axis Revenue and the secondary vertical axis Margin.

Reveal Q15 worked answer and checks
  1. Select A1:C4 and choose Insert > Combo > custom combination. Set Revenue to Clustered Column and Margin to Line. Check Secondary Axis for Margin only.
  2. Select the secondary vertical axis. Choose Format > Current Selection > Format Selection. Under Axis Options > Number, choose Percentage in Category.
  3. Select the chart and choose Chart Design > Add Chart Element > Axis Titles > Primary Vertical. Select the title box, type Revenue and press Enter.
  4. Repeat with Axis Titles > Secondary Vertical and type Margin.

The Revenue columns should represent 1000, 1200 and 900. The Margin line should represent 10%, 15% and 12%. Check that the primary vertical axis is titled Revenue and the secondary vertical axis is titled Margin, with percentage tick labels.

Revenue and Margin use different units. Read each series against its assigned axis; their heights do not compare the amounts directly.
